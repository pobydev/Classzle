## 생활지도 균형 (2026-11-02 변경)

사용자가 정한 순서입니다.

1. **-3과 -2가 몰리지 않게 합니다.** 등급별 합과 유형별(행동, 정서) 항목을 둡니다. 합계만 맞추면 -3이 숨어 버리므로(시험판에서 2.5/3, 2.9/4) 이것을 가장 먼저 봅니다.
2. **반마다 어려움 합계를 맞춥니다.** 음수 생활지도 점수를 더한 값입니다. 예: 두 반에 -2 한 명, -1 두 명이면 -2와 -1 둘로 나눠 -2, -2가 되는 것이 맞습니다.
3. **-1 인원은 합계와 부딪히지 않는 만큼만 맞춥니다.** 그래서 -1 인원 차이는 일부러 커집니다.

- 평균 차이가 조금 커졌습니다. 신규 0.3~1.0, 균형 조정 2.5~3.6입니다. 구간 차이는 그대로입니다.
- 균형 조정이 옮기는 학생이 늘었습니다. 전학년도 반을 되살린 영향이 큽니다.

## 함께 고친 것

- `기본 정보만 출력`을 골라도 생활지도와 관계가 나가던 문제
- 분리 배정과 함께 배정만 보고 '완벽하게 충족'이라고 쓰던 문구. 이제 지금 배정에서 바로 계산합니다
- 추천과 반으로 옮기기가 남녀, 그룹, 전출을 보지 않던 문제
- 신규 배정과 엑셀 다시 올리기가 묻지 않고 지우던 문제
- 저장 파일에 이력이 없고 불러올 때 지우지도 않던 문제
- 전출 안내 문구와 실제 동작이 다르던 문제
- 첫 성별이 30명을 넘으면 번호가 겹치던 문제
- 빈 성별을 여학생으로, 빈 성적과 0점을 500점으로 조용히 넣던 문제. 0점은 그대로 두고, 나머지는 넣되 알립니다
- 빈 이름 행을 조용히 빼던 문제. 값이 있는 행이면 알립니다
- 학생을 지워도 다른 학생의 관계가 남던 문제
- 학급 수를 조용히 바꾸던 문제. 이제 알립니다
- '인공지능 배정 도구' 문구, 배포판의 개발자 도구, 맞춤법 사전 받기
- 쓰지 않던 드래그 패키지와 옛 화면 코드

추가한 것: 되돌리기, 균형 조정, 전학년도 반 섞기(약한 항목), 전학년도 반별 등급 인원표, 읽기 쉬운 변경 이력.

## 시험

| 명령 | 결과 |
| --- | --- |
| `npx vitest run` | 12개 파일 통과(측정 1개 건너뜀), 168개 통과 |
| `npx tsc --noEmit` | 통과 |
| `npm run electron:build-main`, `npm run build` | 통과 |

옛 코드 기준으로 번호, 통계, 교환 검사 시험 14개를 먼저 통과시킨 뒤 코드를 바꿨습니다. 측정은 `BENCH=12 npx vitest run tests/bench --disable-console-intercept`로 다시 할 수 있습니다.

표본 엑셀 2개로 실제 앱을 띄워 끝까지 눌러 봤습니다(`electron .`, 화면 오류 없음): 불러오기, 신규 배정, 추천 10명, 교환, 되돌리기, 어기는 이동 경고, 어긴 것이 없을 때 수정(0명), 일부러 넣은 분리 배정 어김 수정(2명), 균형 조정, 이력, 저장 파일의 이력.
